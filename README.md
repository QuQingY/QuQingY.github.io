# quqingy.github.io

Personal homepage of Qingyu Qu (屈清宇), served via GitHub Pages at <https://quqingy.github.io>.

## Structure

- `index.html` — homepage
- `bio_en.html` / `bio_ch.html` — biography (EN / 中文)
- `perception.html`, `story.html`, `ukulele.html`, `other.html` — personal pages
- `experiments/` — experiment logs, one subfolder per log
  - `experiments/<log-title>/index.html` — log page
  - `experiments/<log-title>/<run-dir>/figures/` — published figures only (raw results are kept offline)
- `imgs/` — shared images
